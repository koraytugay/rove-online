You can select multiple modules and move at once - helpful for the "motor" module.

## Features

### Module Management
- **Drag and Drop** - Click and drag modules to reposition them anywhere on the board
- **Grid Snapping** - Modules automatically snap to a grid for organized layout
- **Multi-Selection** - Select multiple modules (click individual modules or press **A** to select all) and move them together
- **Swap Positions** - Drag one module onto another to swap their positions
- **Flip Modules** - Click the ↻ button on any module to flip between front and back

### Layout Controls
- **Center (C)** - Center all modules on the page based on their center of mass
- **New Game (N)** - Reset all modules to front side and shuffle positions with animation
- **Grid Overlay (G)** - Show/hide available grid positions where modules can be placed

### State Management
- **Save (S) / Restore (R)** - Save current board state and restore it later in the same session
- **Undo (←) / Redo (→)** - Step backward and forward through your move history (up to 50 states)
- **Shareable Links (L)** - Copy a URL that encodes the entire board state - share with others or bookmark different configurations

### Display Options
- **Fullscreen (F)** - Toggle fullscreen mode for distraction-free play
- **Zoom (+/-)** - Zoom in and out (0.5x to 2x) using + and - keys
- **Show/Hide Buttons (H)** - Hide the button panel for a cleaner interface

### Visual Feedback
- **Drag Preview** - When dragging, see a dashed outline showing where the module will snap
- **Selected Highlight** - Selected modules display with a golden glow
- **Toast Notifications** - Brief messages confirm actions like save, undo, and state loading
- **Smooth Animations** - Card flip animation (600ms) and position transitions (300ms)
